# Merapi Ridge Run
Pilot an orange bush plane through six golden gates around a smoking volcano, then bring it home to the valley airstrip. An original offline flight game with procedural terrain, illuminated instruments and synthesised sound. Serve game/ with any static server. Enter starts; arrows or WASD fly; Shift/Ctrl change throttle; R restarts. Screenshot scenes use ?shot=start|play|end&seed=1. Real screenshots are pending capture.
